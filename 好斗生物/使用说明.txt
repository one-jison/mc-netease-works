========================================
《好斗生物》 使用说明 / 参数调整
========================================
打进 MC Studio 就能直接跑，也能直接上传开发者平台。

【想改玩法】
  打开这个文件改数值，重新打包即可：
  battleBrewBehaviorPack\BattleBrewScripts\battleBrewConfig.py

  ★ 优先打生物      PREFER_CREATURE     = True
                     （设成 False 就变回"生物/玩家完全随机"）
  会不会打玩家      TARGET_INCLUDE_PLAYER   = False  （默认关：只对生物生效）
  会不会打生物      TARGET_INCLUDE_CREATURE = True
  挑目标的距离      TARGET_RANGE        = 12.0   格
  发狂时间          ANGRY_DURATION      = 30.0   秒
  多久重挑一次      TARGET_REFRESH      = 1.0    秒
  同时最多几只发狂  MAX_ANGRY           = 16
  打架面对面        FACE_TARGET         = True   （转身正对着对手打）
  摆正朝向频率      FACE_INTERVAL       = 0.1    秒
  咬一口多少伤害    BITE_DAMAGE         = 3.0
  宠物不参战        SKIP_TAMED          = True   （驯服的都不激怒、不被打）
  一律排除的生物    SKIP_TYPES          = ("minecraft:fox",)
  瓶子炸开范围      SPLASH_RADIUS       = 3.5    格
  扔出去的力道      SPLASH_POWER        = 1.25
  自动送几瓶        JOIN_GIVE           = 1

【粒子（没事别改）】
  头顶火气粒子      ANGRY_PARTICLE_NAME = "minecraft:villager_angry"
  咬中粒子          HIT_PARTICLE_NAME   = "minecraft:villager_angry"

  警告：不要改成 minecraft:basic_crit_particle 这类原版暴击粒子。
  它们依赖一个脚本给不了的变量（variable.direction），
  用脚本生成会每一帧报一次 Molang 错误，屏幕会被刷爆。

【关闭某个表现】
  ANGRY_PARTICLE = False   关掉头顶火气
  SOUND_ENABLED  = False   关掉愤怒叫声
  HIT_PARTICLE   = False   关掉咬中的火花
  TIP            = False   关掉聊天栏提示
  LUNGE          = False   关掉主动扑咬

【关闭整个模组】
  ENABLED = False

【出问题时的自助排查】
  在聊天框里输入下面两条，屏幕上会直接告诉你是哪一环断了：

  #好斗诊断
    报告身边 3.5 格内扫到几只生物、当前有几只在发狂、各自盯上了谁。

  #好斗测试
    不扔药水，直接把身边 9 格内的生物全部弄发狂。
    如果这条能让生物打起来，说明"打架"没问题，问题在扔药水那一步；
    如果这条也没反应，那就是"发狂/打架"这一环的问题。

【叫声】
  每种生物叫它自己的声音，配对表在 battleBrewConfig.py 里的 SOUND_BY_TYPE。
  想改某种生物的叫声，就改那一行右边的名字（必须是 sound_definitions.json
  里已经定义过的组，否则会没声音）。
  配不上的生物用 SOUND_FALLBACK（一声低吼）。

【版本记录】
  初版        ：制作
  第一次修改  ：附近有生物时优先打生物
  第二次修改  ：修好"扔了没反应"（引擎每帧心跳不带参数，循环从没跑起来）
  第三次修改  ：打架时面对面；只对生物生效，不再把玩家当目标
  第六次修改  ：加“伙伴保护”——驯服的宠物（狗/猫/狐狸）不激怒、
                也不被当目标；狐狸一律不参与；诊断里会报伙伴数量
  第五次修改  ：叫声改成“每种生物叫自己的声音”（之前全是猫叫）；
                咬中改成撕咬声
  第四次修改  ：换掉会刷屏的粒子（basic_crit 每帧报错，一次会话刷 984 遍）；
                咬中的时候补上一声撕咬
