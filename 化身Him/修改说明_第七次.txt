这次改了什么：天黑得更快
=========================================================

按下技能后【1 秒整】就完全进入天黑状态（以前是 2 秒）。

整个时间轴（时间只往前走，和真实太阳一个方向）：
---------------------------------------------------------
    0.0s        按下技能，开始日落
    1.0s        完全天黑（半夜 18000）
    1.0s ~ 5.5s 全黑（白色冲击波、起火、落雷都在这段里发生）
    5.5s ~ 7.0s 日出过渡，滑回原来的时间
    7.0s        时间精确恢复成释放前的样子

实测曲线（举例）：
    正午释放        6000 → 9000 → 12000 → 15000 → 18000
                    0.0s   0.25s  0.5s   0.75s   1.0s 全黑
    黄昏释放        12000 → 13500 → 15000 → 16500 → 18000
                    0.0s    0.25s   0.5s    0.75s   1.0s 全黑

（技能蓄力是 2 秒，所以你会看到：天黑完了，天上的冲击波才炸出来。）


怎么调
---------------------------------------------------------
himBehaviorPack/HimScripts/himConfig.py

    JUDGE_NIGHT_FADE_IN = 1.0     按下后几秒完全天黑  ← 这次改的就是它
    JUDGE_NIGHT_HOLD = 7.0        整个黑夜阶段几秒（含前后过渡）
    JUDGE_NIGHT_FADE_OUT = 1.5    天亮过渡几秒
    JUDGE_NIGHT_TIME = 18000      半夜
    JUDGE_NIGHT = True            关掉黑夜就改 False
