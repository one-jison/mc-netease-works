这次改了什么：一按下技能，瞬间到雷雨夜
=========================================================

以前：天慢慢黑下来，而且下雨打雷要等一会儿。
现在：按下技能的那一帧，天直接变成半夜，同时下大雨 + 打雷，
      一步到位，没有任何过渡。

时间轴
---------------------------------------------------------
    0.0s         按下技能：瞬间半夜（18000）+ 立刻下雨 + 立刻打雷
    0.0s ~ 5.5s  全黑雷雨（白色冲击波、起火、落雷都在这一段里）
    5.5s ~ 7.0s  天亮过渡（像出日），滑回原来的时间
    7.0s         时间精确恢复成释放前的样子；雨和雷同时停

（技能蓄力是 2 秒，所以你会看到：天已经黑了、雷雨也来了，
然后白色冲击波才爆出来。这是对的，没错。）


技术上怎么实现的
---------------------------------------------------------
· 用的是网易官方天气接口：CreateWeather → SetRaining / SetThunder（世界级）
· 雨量和雷量都是满档 1.0，持续时间跟黑夜一样长（多留 3 秒兜底）
· 技能一结束立刻主动关雨关雷，不等它自己停
· 万一引擎天气组件拿不到，自动改用原版 /weather rain 、/weather thunder 指令兜底
· 如果世界里的「天气更替」被关掉了，技能会自动把它打开，
  技能结束再还回去（不会偷偷改你的世界设置）
· 本来就在下雨 / 打雷的话，技能结束后不会打断你原来的天气


怎么调
---------------------------------------------------------
himBehaviorPack/HimScripts/himConfig.py

    JUDGE_STORM = True            审判时同时来雷雨，关掉就改 False
    JUDGE_STORM_RAIN = 1.0        下雨强度 0~1
    JUDGE_STORM_THUNDER = 1.0     打雷强度 0~1
    JUDGE_NIGHT_FADE_IN = 0.0     按下后几秒天黑（0 = 瞬间）
    JUDGE_NIGHT_HOLD = 7.0        整个黑夜（雷雨）阶段几秒
    JUDGE_NIGHT_FADE_OUT = 1.5    天亮过渡几秒
    JUDGE_NIGHT_TIME = 18000      半夜
    JUDGE_NIGHT = True            关掉黑夜就改 False


没动的东西
---------------------------------------------------------
· 界面上没有紫色框（早就连控件带贴图删干净了）。
· 白色冲击波 + 50 格内起火击杀 + 100 格内全部落雷：没改。
· 四个技能（雷击 / 火球 / 黑暗领域 / 审判）、变身、飞行、手机按钮、电脑快捷键：没改。
· 本来就是黑天时不再折腾时间，但雷雨该来还是会来（黑天也可能没下雨）。
· 技能放完 / 死亡 / 退出 HIM / 离开世界，四处都会把时间和天气还回去。
