================================================================
  《时间回溯》 玩法教程
================================================================

【一、先做出这瓶药】
  无序合成（工作台里随便摆，不用管位置）：
      玻璃瓶 ×1
      时钟   ×1
      末影珍珠 ×1
      红石   ×2
      →  回溯 ×1

  注：时钟就是游戏里那个能看时间的时钟；末影珍珠打末影人掉。

【二、怎么用】
  1. 把「回溯」拿在手里，点一下屏幕喝掉（和喝药水一样）。
  2. 喝完之后，屏幕【左边中间】会出现一颗【回溯】按钮。
  3. 按下去之后，顺序是这样的：
       · 屏幕正中马上转出一个时钟，下面写着「正在回溯...」（转一秒）
       · 按下的一瞬间，先响一声（音效是从那个视频里抽出来的音轨）
       · 同一瞬间，天先直接砸成午夜（全黑），再用四秒一路走到白天：
         黑天 → 天亮 → 白天，一次交替，走完就结束
       · 结束时把时间放回你按下去那一刻（之前是什么时候，还是什么时候）
       · 时钟转满一秒，你身边一百格以内的实体才退回【十秒前】的位置、
         朝向和血量；同一范围内的方块也退回【十秒前】的样子
       · 你自己也会被拉回十秒前站着的位置，而且血量也一起退回十秒前的数值
       · 说白了就是：先转钟、先天亮天黑，一秒之后世界才开始倒带
       · 「十秒前」是按【按下按钮那一刻】算的：等转钟动画的那一秒
         不算在里面，所以自己一定退回按下前十秒站着的位置
  4. 一瓶只能用一次：按下按钮的那一下，屏幕左边那颗【回溯】按钮就消失了，
     这瓶药水就算用完了——想再用，得重新喝一瓶。
     （所以别乱按，看准了再按。）

【三、它能干哪些事】
  · 你打死了一只羊/牛/猪（十秒之内），按一下回溯 → 它原地复活，
    而且站在它十秒前待着的位置。
  · 你用 TNT 炸了一间房子（十秒之内），按一下回溯 → 房子恢复原样。
     （炸掉多少格就记多少格，炸完马上按也修得回来。）
  · 你挖掉方块，掉落物还躺在地上，按一下回溯 → 掉落物跟着消失，方块长回去。
  · 你打死一只猪，掉的经验球还在滚，按一下回溯 → 猪复活，经验球也不见了。
  · 你捡了一堆东西进背包（或者吃掉了经验），按一下回溯 → 多出来的那部分收回去。
  · 你射出去的箭还在飞，按一下回溯 → 箭【不收回来】，而是回到你弓旁边、
    连当时那一箭的速度一起还原，再飞一次（等于这箭重新射出去）。
    就算箭已经插在墙上不动了，回溯后也会带着原来的力道重新飞走。
  · 你挖掉了一片石头，按一下回溯 → 石头长回来。
  · 你在十秒内放了几个方块，按一下回溯 → 那几个方块消失。
  · 你身边的生物跑远了，按一下回溯 → 它们被打回十秒前的位置。
  · 你挨打了，按一下回溯 → 血回到十秒前的数值。
  · 你自己跑远了、掉进洞里了，按一下回溯 → 人直接站回十秒前的位置。

【四、死亡之后】
  · 身上有药水时死掉：屏幕左侧那颗按钮会消失，重生之后也不会回来，
    要重新喝一瓶（和按过按钮之后是一样的）。
  · 如果你是喝完药之后才死的：重生时血量会回到【死前十秒】那个数值
    （装备和背包不受影响）。
  · 也就是说：喝完药再死，等于白赚十秒前的那点血。

【五、手机端 / 电脑端】
  · 手机端：直接用手指点屏幕左侧的【回溯】按钮。
  · 电脑端：按键盘上的 【R】 键（和点那颗按钮完全一样）。
      为什么不让你用鼠标点？——电脑端鼠标锁在准心里，指针根本移不到
      屏幕上那颗按钮上，所以专门配了 R 键。
      想换键：进游戏 设置 → 按键，找到【TimeRewindUse】那一项，自己改。
      （也可以直接改文件：timeRewindConfig.py 里的 USE_KEY_CODE，
        82 = R  71 = G  70 = F  72 = H  74 = J  86 = V）
      按一次只能触发一次，一直按着不会连发；
      药水没了 / 按钮收起来了，按 R 不会有任何反应（不出提示、不出字幕）。

【六、静止药水：让周围停住（新）】
  合成（无序合成，工作台里随便摆）：
      玻璃瓶 ×1
      时钟   ×1
      蓝冰   ×2
      →  静止 ×1

  怎么用：
  1. 拿在手里点一下喝掉。
  2. 喝完之后，屏幕【右边中间】会出现一颗【静止】按钮。
  3. 按一下 → 身边 100 格以内立刻停住：
       · 生物：站着不动，手脚也不动（原生 AI 一起屏蔽了，
         不会追你、不会跑、也不会被打飞）
       · 箭矢 / 雪球 / 火球：停在半空，不掉下来
       · 点燃的 TNT：变成一格 TNT 方块卡在半空 ——
         不闪、不冒烟、也不炸
       · 火焰：不蔓延、不熄灭，一直保持在那里
  4. 再按一下 → 全部恢复：生物接着走，停住的箭接着飞
     （飞出去的速度还是原来那个，不是重新射一次）。
  5. 药效三分钟。这三分钟里想开就开、想关就关，按钮一直亮着；
     停住的时候按钮会保持“按下”的暗色，一眼能看出现在停没停。
  6. 三分钟一到，按钮自动收掉，周围也自动恢复原状，
     屏幕右上角那个倒计时也跟着消失。

  7. 屏幕【右上角】挂着一个小方框：里面是静止药水的图标
     （和物品栏里那瓶药水一样大的 16×16 图标，不挡视野），
     图标下面是剩余时间（3:00 → 2:59 → …），一秒跳一下。
     这是药效倒计时，跟原版药水效果长一个样；药效没了它就没了。

  8. 每按一下按钮（或者按一下 G / 点一下屏幕上的按钮），
     屏幕正中会弹一句提示：
        开启  →  「静止 · 开启」，底下写着「身边的一切都停住了（药效剩余 3:00）」
        解除  →  「静止 · 解除」，底下写着「身边的一切恢复流动」
     两秒后自己收掉，不挡视野。
     身上没药水的时候按下去，还是什么都不会弹。

  9. 点燃的 TNT 被停住之后，会变成【一格 TNT 方块】卡在半空：
      · 不闪、不冒烟、不往下掉、也炸不了。
        （点着的 TNT 自带闪白动画、而且没有接口能把引信按暂停，
          所以干脆把它换成一格真正的 TNT 方块 —— 外形几乎一样，
          但方块天生是静的。）
      · 你什么时候解除静止（再按一下按钮、走远、药效到点），
        那一格就会变回一坨点着的 TNT，接着往下炸。
      · 万一真的炸了（比如刚点着就冻住、剩下的引信实在太短）：
        那一炸一格方块都炸不掉，站在旁边的人一滴血也不会掉
        （要受伤的会被临时护住一下，血少了还会补回来）。
      · 所以你可以放心把 TNT 冻在脚边，也可以冻住之后绕着它走、拆它周围的方块。

  电脑端：按键盘上的 【G】 键（和点那颗按钮完全一样）。
      想换键：进游戏 设置 → 按键，找到【TimeRewindFreeze】那一项，自己改。
      （也可以直接改文件：timeRewindConfig.py 里的 FREEZE_KEY_CODE，
        71 = G  70 = F  82 = R  72 = H  74 = J  86 = V）

  注意：
  · 停住的只是你身边 100 格以内的东西，远处的照常活动。
  · 你走远了，原来停住的那批会自己解冻（范围跟着你走）。
  · 火苗左右摇晃是游戏引擎自己播的贴图动画，逐格暂停做不到；
    但“停止燃烧”是真的：火不蔓延、不熄灭、一直保持在那里。
  · 你身上没有静止药水的时候，按按钮 / 按 G 一点反应都没有。

【七、想改点什么】
  行为包里 TimeRewindScripts/timeRewindConfig.py 全是可以直接改的数字：
      REWIND_SECONDS     退回几秒（默认 10）
      DAY_NIGHT_SECONDS  昼夜飞快交替持续几秒（默认 4）
      DAY_NIGHT_ONCE     True = 只交替一次（先黑天再白天，默认）
                         False = 转完一整圈
      DAY_NIGHT_START    按下先跳到这个时间（18000 = 午夜，最黑）
      DAY_NIGHT_CYCLE    这几秒里走完上面那一段（默认 4）
      BUTTON_SOUND       按下按钮那一声（默认 timerewind.rewind）
      BUTTON_SOUND_VOLUME / BUTTON_SOUND_PITCH   那一声的音量 / 音调
      BUTTON_SOUND_ON    False = 按下不出这一声
      ANIM_WARM_UP       开局先把转钟贴图偷偷加载一遍，第一次放不卡（默认开）
      SELF_CHECK_TICKS   拉回玩家后过几 tick 核对一次有没有到位（默认 5）
      BLOCK_PUT_PER_TICK 每 tick 恢复几格方块（默认 64，调小更顺、调大更快）
      MAX_EXPLODE_BLOCKS 一次爆炸最多记多少格（默认 800）
      EXPLODE_SCAN_RADIUS 拿不到爆炸方块列表时，围着爆点扫几格兜底（默认 6）
      CLEAN_NEW_ITEMS    这十秒里才掉出来的东西（掉落物、经验球）跟着清掉（默认开）
      TRASH_TYPES        哪些实体算“掉落物”，默认 item 和 xp_orb
      REWIND_INVENTORY   把多出来的背包物品收回去（默认开）
      REWIND_EXP         把多涨的经验扣回去（默认开）
      BAG_KEEP           背包 / 经验值最多留多少笔记录（默认 40 笔 = 20 秒）
      DAY_NIGHT_CYCLE    几秒一轮回（默认 5）
      ENTITY_RANGE       身边多少格内的实体跟着回溯（默认 100）
      BLOCK_RANGE        身边多少格内的方块跟着回溯（默认 100）
      BUTTON_SECONDS     按钮留多久，0 = 一直留着
      COOLDOWN_SECONDS   按钮冷却几秒（默认 5）
      REWIND_DELAY       按下后先转几秒的钟，再开始回溯（默认 1）
      ANIM_SECONDS       「正在回溯...」转钟动画放多久（默认 1）
      REWIND_SELF        自己也退回十秒前的位置（默认开）
      REWIND_SELF_HP     连自己的血也一起退回十秒前（默认开）
      PROJECTILE_FLY_AGAIN 抛射物（箭这些）放回出膛点再飞一次（默认开）
      PROJECTILE_TYPES   哪些算抛射物（箭 / 雪球 / 鸡蛋 / 三叉戟 / 末影珍珠…）
      PROJECTILE_KEEP_SPEED 连出膛速度也写回去，插墙上的箭也会再飞（默认开）
      SHOT_KEEP          出膛点最多留多少笔记录（默认 60）
      REWIND_PLAYERS     连别的玩家也一起退回十秒前（默认关）
      KEEP_HP_ON_DEATH   死前喝过药，重生时还原血量（默认开）
      USE_KEY_CODE       回溯按钮的电脑端快捷键键码（默认 82 = R）
      FREEZE_SECONDS     静止药效几秒（默认 180 = 三分钟）
      FREEZE_RANGE       静止影响身边多少格（默认 100）
      FREEZE_AI          True = 连生物原生 AI 一起屏蔽（默认开）
      FREEZE_ANIM        True = 连生物动作一起冻住（默认开）
      FREEZE_MOTION      True = 抛射物停在半空（默认开）
      FREEZE_FIRE        True = 火焰不蔓延不熄灭（默认开）
      FREEZE_PROJECTILE_TYPES 哪些算抛射物（箭 / 雪球 / 火球 / TNT…）
      FREEZE_RESCAN_TICKS 每几 tick 重找一遍身边的实体（默认 5）
      FREEZE_MAX_ENTITIES 一次最多管多少个实体（默认 150）
      FREEZE_KEY_CODE    静止按钮的电脑端快捷键键码（默认 71 = G）
      FREEZE_TIMER_ON    True = 右上角显示药效倒计时方框（默认开）
      FREEZE_TIMER_ICON  倒计时方框里那个图标（默认是静止药水那颗）
      FREEZE_POPUP_ON    True = 按按钮时屏幕正中弹一句提示（默认开）
      FREEZE_POPUP_SECONDS 提示在屏幕上停几秒（默认 2）
      FREEZE_POPUP_ON_TITLE / FREEZE_POPUP_OFF_TITLE   开 / 关时那句标题
      FREEZE_POPUP_ON_SUB  / FREEZE_POPUP_OFF_SUB      开 / 关时底下那行字
      FREEZE_HOLD_STEP   冻住的箭每 tick 朝原方向“挪”多少格（默认 0.01）
                         这个是用来把箭的方向钉住的，别随便改成 0
      FREEZE_HOLD_MAX    补偿量的上限（默认 0.6），防止异常值把箭甩飞
      FREEZE_HOLD_GRAVITY 还没量出真值前先猜的重力大小（默认 0.05）
      FREEZE_STOP_EXPLODE True = 静止期间，被冻住的爆炸物炸不起来（默认开）
      FREEZE_TNT_AS_BLOCK True = 冻住的 TNT 变成一格 TNT 方块，不闪不冒烟（默认开）
                          关掉就退回“定时换一坨新 TNT”的老办法
      FREEZE_EXPLODE_TYPES 哪些算“会炸的东西”（默认 TNT、苦力怕）
      FREEZE_TNT_REFRESH True = 用“原地换一坨新的”让 TNT 引信永远走不完（默认开）
      FREEZE_TNT_REFRESH_TICKS 每几 tick 换一坨新的（默认 40 = 2 秒）
      FREEZE_TNT_KEEP_SECONDS 刚换出来的新 TNT 多久内不算“跑出范围”（默认 0.5 秒）
      FREEZE_BLAST_RADIUS 爆点离被冻住的爆炸物多近才算它炸的（默认 2 格）
      FREEZE_SHIELD_SECONDS 兜底：把要挨炸的对象临时护住多久（默认 0.35 秒）
      FREEZE_HEAL_DELAY   兜底：爆炸后过多久把血补回去（默认 0.08 秒）
