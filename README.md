## 怎么用

1. 打开 **MC Studio**（网易我的世界开发者工具）。
2. 新建或打开一个作品，用「导入」选择对应的 `.zip` 包。
3. 里面每一个包都带了 `manifest.json`（行为包 / 资源包成对），导入后按「运行」就能进游戏试。
4. 地图类（`城市地图_方块都市.zip`、`迷途机关城.zip`、`考前三百天.zip`）是完整存档，按地图方式导入。

每个作品文件夹里还有 `使用说明.txt` / `修改说明*.txt`，写的是这一版改了什么、怎么验证。

## 说明

- 这些作品都是给《我的世界》中国版（网易版）用的，需要 MC Studio 或网易版客户端，Java 版 / 国际基岩版不能直接用。
- 早期版本的文件名里带「旧版」「别导入」的，是历史存档，留着做记录，实际请用最新那一版。
- 代码全部开源，欢迎参考；请勿直接拿去当成自己的作品上传，谢谢。
